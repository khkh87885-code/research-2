# 新增压缩分割研究方案草稿

版本日期：2026-11-08。状态：工程平台与技术验收方案；正式研究参数尚未预注册或冻结。本文件不替代既有 `formal_experiment_protocol.md`，不修改旧研究阈值锁，不把旧失效预警结果充作压缩研究结果。

## 研究问题与分析角色

考察图像编码、分辨率和处理顺序对固定 SAM 乳腺超声分割结果、文件负载和本地处理耗时的影响；在开发数据上建立不依赖人工参考轮廓的图像特征压缩策略，再冻结策略并评估内部留出和跨数据集表现。

现有冻结清单为 BUS-BRA development 213、internal_holdout 851、BrEaST external_test 252。单位是现有清单纳入记录，不能称为全部数据集。保持既有患者划分；已用于旧研究的开发数据历史应在论文披露。患者来源/采集中心/潜在近重复及 SAM 训练重叠未经完整证据确认前，使用“跨数据集验证”，不直接宣称完全独立外部验证。

正式实施前需由研究者冻结：主要准确性终点、效率终点、Dice 允许损失和 HD95 增量界值及依据、主要提示策略、比较族、样本量/精度要求、小病灶阈值、排除规则、分组与版本。代码中的工程默认数值不能充当临床可接受阈值。

实现参考：[Pillow 编码格式与参数文档](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html)；[SciPy 欧氏距离变换 sampling 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.ndimage.distance_transform_edt.html)。具体 HD95/ASSD 聚合约定由下文预先声明，不能假定所有软件定义相同。

## 数据与模型控制

原始数据和权重只读访问，所有派生物写独立运行目录。冻结清单、SAM clean commit、权重 SHA-256、环境版本、代码与配置哈希；运行前后核对原图、掩膜和权重。日志及论文表仅匿名键/聚合信息，患者原始身份映射仅保存在本机私有源清单。无远程推理或患者数据上传。

固定当前 SAM v1 ViT-B、单掩膜输出、无新增后处理；不因压缩条件更换模型或提示。机制实验从原参考掩膜确定固定扩框，每个版本只按实际宽高比例映射。应用验证另用不依赖参考轮廓的固定提示；现有整幅图框仅为技术对照，不能自动等同实用病灶检测器。两种提示分别保存和统计。

## 处理条件

采用同图重复测量：baseline；JPEG Q95/85/75/60/40；PNG 压缩级别/解码像素一致性；可用 WebP/JPEG2000 有损或无损模式；分辨率比例 1.00/0.90/0.75/0.50/0.25，记录 Lanczos 或 Bicubic；CR1 编码、CR2 缩小再编码、CR3 编码解码再缩小、CR4 PNG、CR5 缩小再 PNG。

PNG 等编码等级影响编码效率，不应称图像质量等级。CR3 当前以无损 PNG 存储缩小后的最终负载，中间编码体积另记。所有比较必须使用实际最终文件体积，明确容器与处理顺序。试跑条件在 `configs/smoke.json`；正式条件应在新配置冻结，不能直接把试跑配置当完整因子设计。

图像转换仅接受单帧 8 位输入，保持坐标与 BrEaST 黑底合成约定。高位深、DICOM、多帧和方向信息转换需新增审计。缩小后的预测用最近邻回原图网格评价；原图尺寸恢复不恢复丢失信息。

## 终点及异常约定

逐图记录 Dice、IoU、precision/recall/sensitivity、HD95、ASSD、Boundary F1、绝对相对面积误差，以及预测相对 baseline 一致性、面积变化和空预测标志。边界采用四连通像素表面；HD95 为两方向第 95 百分位的较大值，ASSD 为两方向平均距离的等权平均。缺 spacing 时距离单位为 pixel，默认边界容差是 2 pixel，仅为当前实现约定。

空参考在数据检查时判无效；指标实现对空参考/双空保留缺失状态。非空参考下空预测的重叠指标为 0，precision 和表面距离缺失。损坏、映射失败或模型错误保留失败类型与任务分母，不以自动剔除或填充 0/1 美化。边界指标的有效分母必须随结果报告。

效率包括原字节数、最终字节数、压缩比（最终/原始）、节省率、编码/解码/缩放/推理耗时、GPU 峰值和按带宽模拟上传耗时。模拟上传不能替代真实网络实验。正式计时应冻结硬件、后台负载、预热和重复规则；当前技术试跑不是严格性能基准。

## IACS 开发与锁定

特征仅来自完整原图的分辨率、Laplacian 清晰度、鲁棒噪声代理、局部对比度、边缘及灰度统计；无人工轮廓或标签输入。噪声指标是工程代理量，不是物理标定噪声。

默认规则标记 unvalidated。开发集拟合接口可依据预先设定 Dice 损失/HD95 增量，为每图选择符合约束且文件最小的条件作为开发标签；以患者分组划分训练/内部校准，导出浅树和参数/患者集哈希。标签准确率不是分割非劣或临床安全证据。正式应用需冻结 feature_schema、feature_version、策略文件哈希和比较条件。外部/留出病例只应用，不反复调参。若开发标签不足或不满足约束，报告失败与排除原因，不造训练结果。

## 患者级统计

主要推断单位为患者。同图多压缩版本是配对重复测量，同一患者多图先汇总。条件与 baseline 的差值先取共同有效图像配对，再在患者内平均；报告有效图像、有效患者、失败以及无法配对人数。

当前实现提供患者差值 bootstrap 百分位 95% CI、Wilcoxon 配对检验、按 dataset/prompt/split/metric 定义比较族的 Holm 校正，以及完整患者/条件上的 Friedman 检验。少量患者/条件的近似检验要报告警告；缺失不是随机假设不能默认成立。混合效应是额外接口，须数据充分、收敛和假设核查后解释。正式分析应预先固定检验族与主要结论，避免事后从多终点挑选显著性。

非劣界值未确定时不输出成功的非劣结论。代码支持预设 Dice margin 的区间检查，但该检查不能自动构成临床非劣证明；需研究设计和界值依据。小病灶、病理等亚组未冻结前仅探索性报告。

## 验收和论文交付闸门

1. 单元测试以明确标记的合成几何/表格数据核对指标、无损性、坐标、患者统计、IACS 不使用 GT 及输出安全。
2. 技术试跑仅用少量真实 development 病例，覆盖 baseline/编码/缩放/组合/默认 IACS 与两提示，检查失败、恢复、可追溯性和输入哈希。
3. 冻结正式方案、策略、样本与环境后，再新建正式运行；保留全部失败和缺失。小规模试跑不充正式结果。
4. 出版物导出包括真实逐图/患者/条件 CSV/XLSX、统计表、PNG/SVG/PDF 汇总图、完整方法/版本及限制。论文不得声称已实现尚未验证的外部独立性、上传性能、临床安全或正式 SCI 效能结论。
