# 分阶段实施计划

2026-11-08。依据 PROJECT_AUDIT.md；仅新增扩展，不重构旧项目。

1. **A 审计**：目录、代码、环境、清单/模型核验并生成审计。完成后才开发。
2. **B 备份**：原脚本/方案/锁文件复制到新时间戳备份，保存 SHA-256；导出环境版本。验收：备份逐文件哈希相等。
3. **C 数据与 SAM 适配**：复用现有 CSV/提示框/黑底解码/SAM，增加严格路径、匿名键、质量检查、CPU/CUDA、原图坐标恢复。验收：213/851/252 清单读取、患者隔离、真实模型原图推理。
4. **D 压缩与指标**：baseline、JPEG95/85/75/60/40、PNG级别、WebP/JP2能力检查、Lanczos/Bicubic缩放、CR1–CR5。定义 CR3 最终编码容器避免虚假的体积比较。验收：无损像素一致、原图保护、坐标映射、HD95/ASSD人工几何测试、空掩膜规则。
5. **E 引擎与特征/IACS**：配置快照、源/权重/代码哈希、每任务持久化、失败保留和重试、断点续跑。IACS 先为未验证策略；开发数据拟合后保存锁，外部仅应用。验收：真实少量开发病例原图/压缩推理、恢复/错误分支测试、策略不读取GT。
6. **F 统计与导出**：患者内汇总、配对患者差值/cluster bootstrap、Holm、重复测量/混合模型（满足数据条件时）、非劣界值默认不填。导出CSV/XLSX、PNG/SVG/PDF、只依赖本地资源的HTML工作台与Markdown报告。验收：已知配对例验证、匿名导出、真实结果图表。
7. **G 回归与交付**：重跑关键测试，原旧文件/权重哈希不变；记录实际技术验收与未完成正式研究。导出手册、测试报告、SCI结果状态报告。

每阶段日志单列，先修复失败再进入依赖阶段。合成数据仅供单元测试，真实技术试跑单列为 development_technical_smoke，不能作 SCI 正式效能结论。

正式研究闸门：预先确定主要终点、Dice/HD95界值、子组阈值、患者开发/校准/测试角色与来源独立性；IACS锁定后才能正式运行外部验证。现有开发集已用于旧研究，需如实披露，不改变现有清单。
