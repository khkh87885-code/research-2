# 乳腺超声病灶分割失效预警阈值的跨数据集验证

**正式实验方案 v0.1 · 审阅稿 · 2026-11-05**

本稿在 BUS-BRA 开发子集预实验完成后起草，供审阅和确认。正式阈值与测试结局标为**待计算**，以对应阶段的逐例运行记录为准。

## 1. 研究问题

在病灶位置已知的二维乳腺超声图像上，将 BUS-BRA 开发集确定的病例级复核阈值用于另一数据集时，低质量分割检出率、模拟复核比例和每百例漏报数各变化多少？研究采用公开数据的回顾性模拟，参考轮廓提供病灶定位框和评价依据。

- **H1 · 主假设。** 方法 A 的固定阈值在 BrEaST 与 BUS-BRA 内部留出集上的低质量分割检出率存在差异。
- **H2 · 次要假设。** 方法 A 的同一阈值在两测试集上触发的复核比例存在差异。
- **H3 · 次要假设。** 两种方法在开发集的实际复核人数相同时，方法 B 在 BrEaST 上的低质量分割检出率高于方法 A。

## 3. 固定模型、提示框与评分

采用 Meta 官方 SAM ViT-B，提交 `dca509fe793f601edb92606367a655c15ac00fdf`，权重 `sam_vit_b_01ec64.pth`。沿用单图和 40 例试跑的 Python 3.8.20、PyTorch 2.4.1+cu118、torchvision 0.19.1+cu118 与 float32 权重设置。Meta 公布的预训练来源为 SA-1B，与两套数据的逐图重合情况仍无法从公开资料核实。 [官方源码提交](https://github.com/facebookresearch/segment-anything/commit/dca509fe793f601edb92606367a655c15ac00fdf) · [训练数据说明](https://ai.meta.com/datasets/segment-anything/)

1. 原图转为 RGB，以人工轮廓的外接矩形为基础，左右每侧外扩矩形宽度的 10%，上下每侧外扩高度的 10%，裁到图像边界。固定使用单掩膜输出。
2. **方法 A** 的风险分为 `1 − 初始分割的 SAM 质量分（预测 IoU）`，按模型原始质量分计算。
3. **方法 B** 将初始框向左、右各平移框宽的 5%，向上、下各平移框高的 5%，裁到图像边界。复用同一次图像编码。将四份扰动轮廓分别与初始轮廓求 Dice，风险分为 `1 − 四个 Dice 的平均值`。两个预测轮廓均空时，一致性 Dice 记为 1。若裁切后出现重合的框，按预定四个方向计入并记录该现象。 [提示框扰动研究](https://doi.org/10.1016/j.patrec.2026.08.026)
4. 两法共用初始预测和人工参考轮廓计算质量标签。主分析定义 `Dice < 0.70` 为低质量。该界值用于回顾性评估，风险分阈值用于触发模拟复核，两者分别记录。

## 4. 正式阈值与同分规则

以两种方法都取得有效风险分的开发集患者为共同校准名单。每种方法分别按下列规则定阈值。

1. 以 **20%** 为开发集模拟复核比例目标。候选阈值为该方法的所有不同风险分，以及大于其最高分的最小可表示值。
2. 每个候选阈值按 `风险分 ≥ 阈值` 计算复核人数。选实际比例最接近 20% 的切点。边界同分病例整组处理。若两个切点与目标等距，选复核人数较少的一个。
3. 保存两个未四舍五入的阈值、校准分母、实际复核人数与比例、边界同分人数，以及开发集清单和运行记录。两个测试集使用同一数值和比较规则。

| 锁定的风险分阈值 | 待计算 | 待计算 |

## 5. H1–H3 统计方案

以患者为统计单位。每组的可评分名单为取得有效初始 Dice 和两项有限风险分的患者。每组列出 **N**（可评分患者总数）、**F**（低质量患者数）、**R**（预警患者数）、**TP**（被预警的低质量患者数）和 **FN**（漏报的低质量患者数）。报告检出率 `TP/F`、复核比例 `R/N` 和每百例漏报数 `100 × FN/N`。当某组 F 为 0，检出率标为“不可估计”，并保留原始分子和分母。

| 假设 | 分析和报告规则 |
|---|---|
| **H1 · 主要检验** | 对方法 A 计算 **BrEaST 检出率减 BUS-BRA 内部留出集检出率**，单位为百分点。用 Newcombe 独立比例差的 Wilson 评分区间（方法 10）给出双侧 95% 置信区间。区间排除 0 作为差异证据，点估计和区间都按实测报告。 |
| **H2 · 次要估计** | 对方法 A 计算 **BrEaST 复核比例减 BUS-BRA 内部留出集复核比例**，使用同一独立比例差区间。同步列出各组低质量比例和合格病例中的预警比例。 |
| **H3 · 配对比较** | 在 BrEaST 的同一批低质量病例中，统计两法均检出、仅 A 检出、仅 B 检出、两法均漏报。报告 **B 减 A** 的检出率差和 Newcombe 配对评分区间（方法 10），同步报告全体病例中 B 减 A 的复核比例。若两法开发集实际复核人数不同，标记 H3 的预算匹配条件未满足，并将该对照作为描述性结果。 |

H1 为唯一主要推断，H2、H3 和补充分析报告名义 95% 区间及原始计数。区间对应这次锁定规则下、两套指定数据的估计。 [独立比例差区间](https://pubmed.ncbi.nlm.nih.gov/9595617/) · [配对比例差区间](https://pubmed.ncbi.nlm.nih.gov/9839354/)

**补充分析。** 沿用两条锁定的风险分阈值，将低质量界值分别改为 Dice < 0.50 和 Dice < 0.80，报告低质量病例数、检出率及漏报数。另在 BrEaST 上用两种分数分别排序，取同样数量、最接近 20% 的高风险病例，同分按 `Case_ID` 字典序排列。这项等量复核对照与固定阈值主分析分开报告。

## 6. 真实性与执行顺序

1. 审阅通过后记录方案冻结日期和版本。用完整开发集逐例计算，保存实际校准人数与阈值。
2. 冻结两个阈值后，按患者清单运行内部和外部测试。每行记录数据来源、患者和图像编号、模型版本、预测 Dice、两项风险分、两个预警结果和技术故障状态。
